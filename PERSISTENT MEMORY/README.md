# 🧠 BROWSER AGENT - PERSISTENT MEMORY & SELF-LEARNING LEDGER

Dokumen ini adalah pusat memori persisten, catatan pengalaman (*Experience Ledger*), aturan anti-kesalahan (*Anti-Pattern Vault*), serta pustaka skill dan agent otonom yang dipelajari dan dikembangkan secara mandiri oleh AI Agent.

---

## 📂 Struktur Direktori Memori:

| Folder | Deskripsi | Format |
| :--- | :--- | :--- |
| `user_profile/` | Profil pengguna, preferensi gaya kerja, aturan personal (Gemini-style). | Markdown `.md` & SQLite |
| `experience_ledger/` | Rangkuman intisari pengalaman padat dari setiap sesi percakapan. | Markdown `.md` & SQLite |
| `anti_patterns/` | Catatan kesalahan masa lalu & solusi pencegahan permanen. | Markdown `.md` & SQLite |
| `autonomous_skills/` | Workflow & skill baru yang diracik dan dioptimasi mandiri oleh AI. | Markdown `.md` & SQLite |
| `autonomous_agents/` | Sub-agent spesialis baru yang dilahirkan sendiri oleh Master Agent. | Markdown `.md` & SQLite |

---

## ⚡ Prinsip Operasional:
1. **Zero AI Slop**: Memori menyajikan fakta konkret, kode teruji, dan aturan nyata tanpa basa-basi klise.
2. **Dual-Sync**: Sinkronisasi otomatis dua arah antara file Markdown di folder ini dan database SQLite lokal (`chat_history.db`).
3. **Continuous Evolution**: Skill dan aturan terus disempurnakan (`v1.0 -> v1.1`) saat ditemukan alur kerja yang lebih cepat atau solusi yang lebih tangguh.
